Reason in the first person and in the present tense, and take the limbs separately: for each thing that has to be done in this matter, ask which enactment governs it, on what date that question turns, and what the savings provision does with that date. Say expressly which code and which section you are applying to each limb, and do not assume that the answer is the same for all of them.
