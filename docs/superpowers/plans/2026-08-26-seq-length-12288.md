# Sequence Cap 12,288 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the production lane's `max_seq_length` from 8192 to 12,288 and close the memory-guard hole that raise opens, so a future long row cannot OOM a MAIN run mid-session.

**Architecture:** Four code/config tasks, then one operator-run requalification gate on Kaggle. At `bs=1` the collator pads to the row, so the cap raise is near-free today — the work is in proving the new ceiling survivable and in fixing `_ReservedCeiling`, whose every-25th-step sampling assumes a fixed bucket that stops holding once the cap exceeds the longest row.

**Tech Stack:** Python 3.12, pytest, PyYAML, unsloth/TRL/transformers (pinned), Kaggle 2x T4 + torchrun DDP.

**Spec:** `docs/superpowers/specs/2026-08-26-seq-length-12288-design.md`

## Global Constraints

- **No Claude/Anthropic attribution** in any commit message, file, or comment. No `Co-Authored-By` trailer.
- **The 13.5 GiB abort line does not move.** `check_vram_reserved(limit_gib=13.5)` and `_ReservedCeiling(limit_gib=13.5)` keep that value. A run that trips it is the gate working.
- **Do not swap the model repo.** `unsloth/Qwen3-8B-unsloth-bnb-4bit` and its pinned revision stay; the standard-quant rung's −1.31 GiB is held in reserve.
- **Do not add a `--gradient-accumulation-steps` override.** Rejected in the spec: at `ga=1` the LoRA grad buffer is freed between micro-batches, measuring the ceiling ~0.15 GiB low.
- **Do not change `MAX_CHUNK_TOKENS` or the 24,000-char proxies** in `curated.py` / `replay.py`. Explicitly out of scope.
- Run the full suite with `python -m pytest tests/ -q` (75 tests collected before this plan).

**Interfaces:**
- Consumes: nothing.

**Why:** `_ReservedCeiling`'s docstring justifies its every-25th sampling with *"the full memory shape exists by step 1-2 at bs=1 with a fixed bucket"*.
```python
def ceiling_check_due(step: int, early: int, every: int) -> bool:
    """Whether the reserved-VRAM ceiling should be read at this step.

    The `every` sampling existed because at seq 8192 with drop-never-truncate
    the bucket was FIXED - every row truncated to the same length, so the full
    memory shape appeared by step 1-2 and later steps could only differ by
    fragmentation. Above the longest row the cap stops binding and the bucket
    is variable: the peak step is whichever step carries the longest row, and
    sampling can miss it entirely. Hence every=1 at the call site."""
    return step <= early or step % every == 0
```
